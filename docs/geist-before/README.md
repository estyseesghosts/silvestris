# Geist before-refinement captures

These are the accepted Geist Light and Geist Dark renders at 100, 125, 150,
175 and 200% from the clean baseline commit `d575f34`. `manifest.json` and
`reasons.json` are the accepted Geist entries copied from
`goldens/manifest.json` and `goldens/reasons.json`.

They are *before* references for the refinement described in
[`../geist-refinement.md`](../geist-refinement.md). Do not accept new goldens
by regenerating these files. Aqua references remain in `goldens/renders`.
